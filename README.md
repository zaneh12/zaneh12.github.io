# Zane Hassoun Personal Site

This is my personal website and GitHub Pages site.

It focuses on:

- my work in risk and forecasting
- fixed income, MBS, and rate-driven problems
- thesis and paper links
- projects and code
- a more personal about page

## Public Pages

- `index.html` - homepage
- `projects.html` - selected projects and links
- `about-me.html` - background, work, and interests
- `mbs.html` - first article / notes on MBS hedging
- `crypto-etf-dashboard/index.html` - standalone crypto ETF hedge note
- `contact.html` - contact links

## Notes

- Older notes, meeting pages, experiments, and unused artifacts have been moved into `archive/`.
- The live site is meant to stay small, clean, and focused on the work I want to show publicly.
- Styling lives in `assets/css/site.css`.

## Local Editing

When I update the site:

1. edit the public HTML pages
2. keep new pages consistent with the existing layout
3. add any old or unused material to `archive/`
4. commit and push to GitHub Pages
